# Security Policy

## Supported Versions

Only the latest released version of Workbay is supported with security fixes.
Older versions should be upgraded before reporting an issue against them.

| Version        | Supported          |
| -------------- | ------------------ |
| Latest release | :white_check_mark: |
| Older releases | :x:                |

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Instead, report it privately through GitHub's
[Security Advisories](../../security/advisories/new) for this repository
("Report a vulnerability" under the Security tab). This keeps details out of
public view until a fix is available.

Include as much detail as you can: the affected version, the scenario that
triggers it (server-side duplication, crash, data loss, etc.), and steps to
reproduce.

You should get an initial response within a few days. If the report is
confirmed, a fix will be prioritized and a new release published; you'll be
credited in the release notes unless you'd prefer otherwise.
